# elotech-legal

Legal pages for Elo Tech apps, served with GitHub Pages.

| App | Page | Public URL |
|---|---|---|
| Block Puzzle (Android) | [`block-puzzle/index.html`](block-puzzle/index.html) | https://mohamedhamed256.github.io/elotech-legal/block-puzzle/ |

GitHub Pages must be enabled for this repository: **Settings → Pages → Build and deployment →
Source: Deploy from a branch → Branch: `main` / `(root)`**.

The source text of the Block Puzzle policy lives in
`MohamedHamed256/block-puzzle-android` → `store/privacy-policy.md`. Keep both in sync.
